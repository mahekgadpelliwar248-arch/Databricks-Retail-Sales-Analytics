# Databricks Retail Sales Analytics

## Project Overview
This project analyzes retail sales data using Databricks to identify sales trends, top-performing products, regional performance, and category-wise contributions.

## Tools Used
- Databricks SQL
- Unity Catalog
- Databricks Genie
- AI/BI Dashboards

## Key Findings
- Total Sales Revenue: 5,019,265.23
- Total Quantity Sold: 25,355
- Total Sales Records: 1,000
- Distinct Products: 100
- The North region recorded the highest sales.

## Project Files
- `Retail_Sales_Analysis.sql` – SQL queries for sales analysis.

## Learning Outcome
Gained practical experience in SQL analysis and explored data governance, AI-assisted analytics, and dashboard visualization using Databricks.
